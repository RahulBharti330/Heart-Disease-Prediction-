# Heart-Disease-Prediction-
It is Heart disease prediction model which consists of multiple algorithms.

- Developed a multi-model system to predict heart disease risk using Logistic Regression, Random Forest, and K-Nearest Neighbors (KNN).
- Preprocessed healthcare data with Pandas and Scikit-learn, performing feature selection and model tuning for optimal performance.
- Evaluated model accuracy, precision, recall, and F1-score to ensure reliable and actionable predictions for healthcare decision-making.
